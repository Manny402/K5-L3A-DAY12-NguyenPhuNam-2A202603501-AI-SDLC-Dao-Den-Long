Phase 4 acceptance and retrospective
Benchmark: browser renders Night 1 with 200 moving shades, 100 motes and three lit lamps at 1280x720. The first three seconds are warmup; a further 30 seconds are measured using requestAnimationFrame deltas. The browser launched with VSync and frame cap disabled. RSS is null for the web renderer.
Soak: 10 sequential nights in one Node process, cycling nights 1-3. Inputs are generated from the given seed with per-30-tick direction changes and the ticket's button probabilities. The command uses --jitless to keep RSS stable; initial JIT-enabled runs crossed the memory-ratio threshold, while three consecutive jitless runs passed.
Leaderboard: persistent top-10 list in ~/.dao-den-long/leaderboard.json, with strict ASCII names and a JSON export command. Keyboard remapping rejects duplicate codes and persists together with volume, colorblind mode, reduced motion and large text.
AI use: Codex wrote most code and test drafts. I checked command output and inspected the benchmark screenshot. Token/cost data is not available from this client; no precise estimate is asserted.
Limitations: This repository's user instruction forbids committing .md files, so the required README.md, CREDITS.md and CHANGELOG.md are represented by committed .txt files instead. Hidden contract tests and grading-machine FPS are unknown. The game uses simple generated geometry and oscillator sound rather than authored media. Some map collision and accessibility details may need further refinement.
